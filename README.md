# Fraud Detection System

A machine learning project to detect fraudulent financial transactions.  
Built with **Python**, **Pandas**, and **Scikit-Learn**, the model applies:

- **Feature scaling**
- **Categorical encoding**
- **Class balancing techniques**  

These steps help handle the imbalanced nature of fraud detection datasets.  
The final model achieved **94% accuracy** in identifying fraudulent transactions.

## 🚀 Features
- Preprocessing with scaling & encoding  
- Handling imbalanced data with resampling  
- Training ML models (Logistic Regression, Random Forest, etc.)  
- Evaluation with accuracy, precision, recall, and F1-score
- - **Streamlit app for real-time fraud detection**  

---

## 🛠️ Tech Stack
- Python 3.x  
- Pandas  
- NumPy  
- Scikit-Learn  
- Matplotlib / Seaborn (for visualization)
- Streamlit
